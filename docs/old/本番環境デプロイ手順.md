# 本番環境デプロイ手順

## なぜ本番環境が必要か？

LINE連携機能は、LINEサーバーからWebhookを受信する必要があります。
- ❌ **ローカル環境**: `localhost` は外部からアクセスできないため、LINEからのWebhookが届かない
- ✅ **本番環境**: GitHub Pagesなど公開URLがあれば、LINEからのWebhookを受信可能

## デプロイ手順

### 1. Gitリポジトリの確認

```bash
cd c:\Users\pon10\OneDrive\デスクトップ\tenkai
git status
```

### 2. 変更をコミット

```bash
# すべての変更をステージング
git add .

# コミット
git commit -m "LINE連携機能の実装完了"

# GitHubにプッシュ
git push origin main
```

### 3. GitHub Pagesの設定確認

1. GitHubリポジトリを開く
2. Settings → Pages
3. Source: GitHub Actions が選択されていることを確認
4. デプロイが自動で開始される（数分かかる）

### 4. デプロイ完了を確認

1. Actions タブでデプロイ状況を確認
2. 緑のチェックマークが表示されたら完了
3. GitHub PagesのURLを確認
   - 例: `https://ユーザー名.github.io/リポジトリ名/`

## トラブルシューティング

### デプロイが失敗する

**原因**: GitHub Actionsの権限不足
**解決策**:
1. Settings → Actions → General
2. Workflow permissions → Read and write permissions を選択
3. 再度プッシュ

### LINE連携が動作しない

**原因1**: Webhook URLが間違っている
**解決策**: LINE Developersで以下を確認
```
https://wpagpmjjgwsnowvnhmml.supabase.co/functions/v1/line-webhook
```

**原因2**: Supabase Functionsが動作していない
**解決策**: Supabaseダッシュボード → Functions → Logs でエラー確認

**原因3**: 環境変数が設定されていない
**解決策**: Supabaseダッシュボード → Settings → Edge Functions → Secrets で以下を確認
- `LINE_CHANNEL_ACCESS_TOKEN`
- `LINE_CHANNEL_SECRET`
