# 運営者向け設定ガイド

## Gemini AI機能の設定

### 現在の実装

- **変更前**: 各ユーザーが自分のAPIキーを設定
- **変更後**: 運営者（あなた）のAPIキーを全ユーザーで共有

### 設定手順

#### 1. config.jsにAPIキーを設定

`config.js` ファイルを開いて、以下の部分を編集：

```javascript
const CONFIG = {
  // Gemini API Key（運営者のキー）
  GEMINI_API_KEY: 'YOUR_GEMINI_API_KEY_HERE',  // ← ここにあなたのAPIキーを貼り付け
  
  // その他の設定
  APP_NAME: 'マッチングアプリ管理システム',
  VERSION: '1.0.0'
};
```

**例:**
```javascript
GEMINI_API_KEY: 'AIzaSyABC123def456GHI789jkl012MNO345pqr',
```

#### 2. 動作確認

1. ブラウザでアプリを開く
2. ログインする
3. ホーム画面の「マチアプネキからのアドバイス」を確認
4. AIからのアドバイスが表示されればOK

### セキュリティ対策

#### ⚠️ 重要: config.jsをGitHubにプッシュしない

`.gitignore` に以下を追加：

```
config.js
```

#### 本番環境での推奨設定

本番環境では環境変数を使用することを推奨：

1. **Netlify/Vercelの場合**
   - 環境変数 `GEMINI_API_KEY` を設定
   - ビルド時に自動的に読み込まれる

2. **GitHub Pagesの場合**
   - GitHub Secretsに `GEMINI_API_KEY` を設定
   - GitHub Actionsで環境変数として注入

### プロンプトの改善内容

新しいプロンプトは以下の情報を分析します：

1. **登録中の相手数**
2. **ステータス別の内訳**（本命、あり、わからない、など）
3. **今後の予定数**
4. **未記入のデート数**
5. **最近のデート履歴**（最大3件）

**アドバイスのポイント:**
- 未記入のデートがあれば振り返りを促す
- 本命の相手がいれば応援する
- 予定があれば準備を勧める
- 活動が停滞していれば動き出しを促す

**出力:** 50文字以内の明るく前向きなアドバイス

### プロンプトのカスタマイズ

`index.js` の `loadAIAdvice` 関数内のプロンプトを編集することで、アドバイスの内容を変更できます。

## トラブルシューティング

### 「AIアドバイス機能は現在設定中です」と表示される

**原因**: config.jsにAPIキーが設定されていない

**解決方法**:
1. config.jsを開く
2. `GEMINI_API_KEY` に正しいAPIキーを設定
3. ブラウザをリロード

### 「アドバイスの生成に失敗しました」と表示される

**原因1**: APIキーが無効

**解決方法**:
1. Google AI Studioで新しいAPIキーを発行
2. config.jsを更新

**原因2**: API利用制限

**解決方法**:
- Gemini APIの無料枠を超えている可能性
- Google Cloud Consoleで使用状況を確認

### ブラウザのコンソールエラー

F12キーで開発者ツールを開き、Consoleタブでエラーを確認：

- `CONFIG is not defined` → config.jsが読み込まれていない
- `403 Forbidden` → APIキーが無効
- `429 Too Many Requests` → API利用制限
