# 1️⃣ Gemini AI アドバイス機能

## 何ができるの？

ホーム画面に「今日のアドバイス」が表示されます。
例: 「本命の山田さんとのデートが近づいています。楽しい時間を過ごしてください！」

## 設定手順

### 【手順1】Google AI StudioでAPIキーを取得

#### 1-1. サイトにアクセス
```
https://makersuite.google.com/app/apikey
```
↑このURLをブラウザで開く

#### 1-2. Googleアカウントでログイン
- 普段使っているGmailアカウントでOK
- 初めての場合は利用規約に同意

#### 1-3. APIキーを作成
1. 画面に「Get API key」または「Create API key」ボタンがある
2. クリックする
3. 「Create API key in new project」を選択
   - または既存のプロジェクトがあればそれを選択
4. 数秒待つと、APIキーが表示される

#### 1-4. APIキーをコピー
```
例: AIzaSyABC123def456GHI789jkl012MNO345pqr
```
- 「Copy」ボタンをクリック
- または手動で全文字を選択してコピー

⚠️ **重要な注意事項**
- このキーは誰にも教えないでください
- スクリーンショットをSNSに投稿しないでください
- 紛失した場合は新しいキーを作り直せます

---

### 【手順2】アプリに設定

#### 2-1. アプリにログイン
1. ブラウザでアプリを開く
2. メールアドレスとパスワードでログイン

#### 2-2. アカウント管理画面を開く
1. 画面下部のナビゲーションバーを見る
2. 「アカウント」をクリック

#### 2-3. Gemini設定を見つける
1. 画面を下にスクロール
2. 「Gemini AI設定」というセクションを探す

#### 2-4. APIキーを入力
1. 「Gemini APIキー」という入力欄がある
2. 先ほどコピーしたAPIキーを貼り付け（Ctrl+V または 右クリック→貼り付け）
3. 「AIアドバイス機能を有効化」のチェックボックスにチェックを入れる
4. 「保存」ボタンをクリック

#### 2-5. 動作確認
1. 画面下部のナビゲーションバーから「ホーム」をクリック
2. 「今日のアドバイス」カードを探す
3. AIからのメッセージが表示されていればOK！

---

### 🔧 トラブルシューティング

#### 「APIキーが無効です」と表示される
**原因**: APIキーが正しくコピーされていない

**解決方法**:
1. APIキーの前後にスペースが入っていないか確認
2. 全文字がコピーされているか確認（長いです！）
3. Google AI Studioで新しいキーを作り直す

#### アドバイスが表示されない
**原因1**: 機能が有効化されていない
- 「AIアドバイス機能を有効化」にチェックが入っているか確認

**原因2**: プロフィールが登録されていない
- 最低1件のプロフィールを登録してください

**原因3**: APIの利用制限
- Gemini APIは無料枠があります
- 1日に何度もアクセスすると制限される場合があります
- 翌日になれば復活します

# 2️⃣ LINE Notify 連携

## 何ができるの？

LINEで通知を受け取れます。
- デートの前日にリマインダー（将来実装予定）
- 重要なお知らせ

## 設定手順

### 【手順1】LINE Notifyでトークンを取得

#### 1-1. サイトにアクセス
```
https://notify-bot.line.me/my/
```
↑このURLをブラウザで開く

#### 1-2. LINEアカウントでログイン
- スマホのLINEアプリと同じアカウントでログイン
- QRコードまたはメールアドレスでログイン

#### 1-3. トークンを発行
1. 画面右上の「トークンを発行する」ボタンをクリック
2. 以下を入力:
   - **トークン名**: 「マッチングアプリ管理」（自由に決めてOK）
   - **通知を送信するトークルーム**: 「1:1でLINE Notifyから通知を受け取る」を選択
3. 「発行する」ボタンをクリック

#### 1-4. トークンをコピー
```
例: abc123XYZ456def789GHI012jkl345MNO678pqr
```
- 画面に表示されたトークンをコピー

⚠️ **超重要な注意事項**
- **このトークンは一度しか表示されません！**
- 今すぐコピーしてください
- 紛失した場合は新しいトークンを発行し直す必要があります
- このトークンは誰にも教えないでください

---

### 【手順2】アプリに設定

#### 2-1. アプリにログイン
1. ブラウザでアプリを開く
2. メールアドレスとパスワードでログイン

#### 2-2. アカウント管理画面を開く
1. 画面下部のナビゲーションバーから「アカウント」をクリック

#### 2-3. LINE連携セクションを見つける
1. 「LINE Notify連携」というセクションを探す
2. 「未連携」と表示されているはず

#### 2-4. トークンを入力
1. 「LINEと連携する」ボタンをクリック
2. ポップアップ（小さなウィンドウ）が表示される
3. 先ほどコピーしたトークンを貼り付け
4. 「連携する」ボタンをクリック

#### 2-5. 動作確認
1. 「連携に成功しました」というメッセージが表示される
2. **スマホのLINEアプリを開く**
3. 「LINE Notify」からメッセージが届いているか確認
   - 「マッチングアプリ管理と連携しました」という通知が来ればOK！
4. アプリのアカウント画面に「連携済み」と表示される

---

### 🔧 トラブルシューティング

#### 「トークンが無効です」と表示される
**原因**: トークンが正しくコピーされていない

**解決方法**:
1. トークンの前後にスペースが入っていないか確認
2. 全文字がコピーされているか確認
3. LINE Notifyで新しいトークンを発行し直す

#### LINEに通知が届かない
**原因1**: LINE Notifyをブロックしている
- LINEアプリで「LINE Notify」を検索
- ブロックを解除

**原因2**: 通知設定がオフ
- LINEアプリの設定を確認

**原因3**: トークンが無効
- LINE Notifyのサイトで、発行したトークンが有効か確認

#### 連携を解除したい
1. アプリのアカウント画面を開く
2. 「LINE連携を解除」ボタンをクリック
3. 確認ダイアログで「OK」をクリック
4. （推奨）LINE Notifyのサイトでもトークンを削除

# 3️⃣ 画像アップロード機能

## 使い方

### プロフィールに写真を追加

#### 1. プロフィール編集画面を開く
- 「プロフィール一覧」から編集したい人をクリック
- または「新規登録」をクリック

#### 2. 写真を選択
1. 「写真」の項目を探す
2. 「ファイルを選択」ボタンをクリック
3. スマホ/PCから画像を選択

#### 3. トリミング（切り抜き）
1. 選択した画像が表示される
2. 画像をドラッグして切り抜き範囲を調整
3. ピンチイン/アウトで拡大縮小
4. 「決定」ボタンをクリック

#### 4. 保存
1. 他の項目も入力
2. 「保存」ボタンをクリック
3. プロフィール一覧で写真が表示されればOK！

### 対応している画像形式
- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif)
- WebP (.webp)

### 推奨サイズ
- 最小: 300×300ピクセル
- 最大: 5MB

# 📞 サポート

## よくある質問

**Q: APIキーやトークンを変更したい**  
A: アカウント管理画面で新しいものを入力して保存してください

**Q: 料金はかかりますか？**  
A: 
- Gemini API: 無料枠あり（月60リクエストまで無料）
- LINE Notify: 完全無料
- Supabase: 無料枠あり

**Q: データは安全ですか？**  
A: 
- APIキーとトークンは暗号化されて保存
- Supabaseのセキュリティ機能で保護
- あなた以外はデータを見られません

**Q: スマホでも使えますか？**  
A: はい、スマホのブラウザで全機能が使えます

**Q: オフラインでも使えますか？**  
A: 基本機能は使えますが、AIアドバイスとLINE通知はインターネット接続が必要です

# 🔒 セキュリティとプライバシー

## 大切な情報の管理

### APIキーとトークン
- 絶対に他人に教えない
- SNSに投稿しない
- スクリーンショットを共有しない

### 紛失した場合
1. すぐに新しいキー/トークンを発行
2. 古いキー/トークンを削除
3. アプリで新しいものに更新

### 定期的な確認
- 3ヶ月に1回、キーとトークンを更新することを推奨
