# 初期設定ガイド

このアプリを使い始めるための設定手順です。

---

## 1. Gemini AI アドバイス機能の設定

AIがあなたの恋愛をサポートしてくれる機能です。

### ステップ1: Gemini APIキーを取得

1. **Google AI Studioにアクセス**
   - ブラウザで https://makersuite.google.com/app/apikey を開く
   - Googleアカウントでログイン

2. **APIキーを作成**
   - 「Create API key」ボタンをクリック
   - 既存のGoogle Cloudプロジェクトを選択するか、新規作成
   - 生成されたAPIキーをコピー（例: `AIzaSyABC123...`）
   
   ⚠️ **重要**: このキーは他人に見せないでください

### ステップ2: アプリに設定

1. **アプリにログイン**
   - ブラウザでアプリを開く
   - ログインする

2. **アカウント管理画面を開く**
   - 画面下のナビゲーションから「アカウント」をクリック

3. **Gemini設定セクションを探す**
   - 下にスクロールして「Gemini AI設定」を見つける

4. **APIキーを入力**
   - 「Gemini APIキー」の入力欄に、コピーしたAPIキーを貼り付け
   - 「AIアドバイス機能を有効化」にチェックを入れる
   - 「保存」ボタンをクリック

5. **動作確認**
   - 「ホーム」画面に戻る
   - 「今日のアドバイス」カードにAIからのメッセージが表示されればOK！

### トラブルシューティング

- **「APIキーが無効です」と表示される**
  → APIキーをコピーミスしていないか確認
  → Google AI Studioで新しいキーを作り直す

- **アドバイスが表示されない**
  → 「AIアドバイス機能を有効化」にチェックが入っているか確認
  → プロフィールを1件以上登録しているか確認

## 2. LINE Notify 連携の設定

LINEで通知を受け取れるようにする機能です。

### ステップ1: LINE Notifyトークンを取得

1. **LINE Notifyにアクセス**
   - ブラウザで https://notify-bot.line.me/my/ を開く
   - LINEアカウントでログイン

2. **トークンを発行**
   - 「トークンを発行する」ボタンをクリック
   - トークン名を入力（例: 「マッチングアプリ管理」）
   - 通知を送信するトークルームを選択
     - 「1:1でLINE Notifyから通知を受け取る」を選択（推奨）
   - 「発行する」ボタンをクリック

3. **トークンをコピー**
   - 表示されたトークンをコピー（例: `abc123XYZ...`）
   
   ⚠️ **重要**: このトークンは一度しか表示されません！
   ⚠️ **重要**: このトークンは他人に見せないでください

### ステップ2: アプリに設定

1. **アプリにログイン**
   - ブラウザでアプリを開く
   - ログインする

2. **アカウント管理画面を開く**
   - 画面下のナビゲーションから「アカウント」をクリック

3. **LINE連携セクションを探す**
   - 「LINE Notify連携」を見つける

4. **トークンを入力**
   - 「LINEと連携する」ボタンをクリック
   - ポップアップが表示される
   - コピーしたトークンを貼り付け
   - 「連携する」ボタンをクリック

5. **動作確認**
   - 連携成功のメッセージが表示される
   - LINEに「マッチングアプリ管理と連携しました」という通知が届けばOK！
   - アカウント画面に「連携済み」と表示される

### トラブルシューティング

- **「トークンが無効です」と表示される**
  → トークンをコピーミスしていないか確認
  → LINE Notifyで新しいトークンを発行し直す

- **LINEに通知が届かない**
  → トークン発行時に選択したトークルームを確認
  → LINE Notifyをブロックしていないか確認

- **連携を解除したい**
  → アカウント画面の「LINE連携を解除」ボタンをクリック
  → LINE Notify側でもトークンを削除することを推奨

## 3. 画像アップロード機能の確認

プロフィールに写真を追加できる機能です。

### 使い方

1. **プロフィール編集画面を開く**
   - 「プロフィール一覧」から編集したい人をクリック
   - または新規登録画面を開く

2. **写真を選択**
   - 「写真」の「ファイルを選択」をクリック
   - 画像ファイルを選択

3. **トリミング**
   - 画像が表示される
   - ドラッグして切り抜き範囲を調整
   - 「決定」ボタンをクリック

4. **保存**
   - 「保存」ボタンをクリック
   - プロフィール一覧で写真が表示されればOK！

## よくある質問

**Q: APIキーやトークンを変更したい**  
A: アカウント管理画面で新しいものを入力して保存してください

**Q: 料金はかかりますか？**  
A: Gemini APIは無料枠があります。LINE Notifyは完全無料です

**Q: データは安全ですか？**  
A: APIキーとトークンはSupabaseに暗号化されて保存されます

**Q: スマホでも使えますか？**  
A: はい、スマホのブラウザで全機能が使えます
