# 設計書と実装の差分

## 1. 新規追加機能

### 1.1 GitHub Secretsによる環境変数管理
**実装箇所:** `.github/workflows/deploy.yml`

**内容:**
- config.jsをGitHub Secretsから動的生成
- APIキーやトークンをリポジトリに含めない安全な管理方法を実装

**設計書への追加が必要:**
- デプロイ手順書にGitHub Secrets設定手順を追加
- セキュリティ設計書にAPIキー管理方法を記載

---

### 1.2 Gemini APIモデル名の更新
**実装箇所:** `index.js`

**変更内容:**
- 旧: `gemini-pro`
- 新: `gemini-2.5-flash`

**理由:** Gemini APIのモデル名が更新され、v1betaでは`gemini-2.5-flash`が推奨モデルとなった

**設計書への追加が必要:**
- 基本設計書の外部インターフェース設計を更新
- 詳細設計書のAI関連関数仕様を更新

---

### 1.3 config.jsの.gitignore追加
**実装箇所:** `.gitignore`

**内容:**
```
# API Keys
config.js
```

**設計書への追加が必要:**
- 開発環境セットアップ手順にconfig.jsの作成方法を追加
- config.example.jsの存在を明記

## 6. 優先度

1. 基本設計書の外部インターフェース設計更新（Gemini API、LINE Notify）
2. 詳細設計書のAI関連関数仕様更新
3. デプロイ手順書の作成（GitHub Secrets設定）

### 中優先度（次回対応）
1. notification_logsテーブルの削除または実装
2. 詳細フィルタのLocalStorage保存機能実装
3. テスト設計書の作成

### 低優先度（必要に応じて対応）
1. 処理フロー図の作成
2. セキュリティ設計書の作成
