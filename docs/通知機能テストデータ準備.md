# 通知機能テストデータ準備SQL

## 前提条件
- LINE Notifyトークンが必要です
- まだ取得していない場合は、以下の手順で取得してください

### LINE Notifyトークンの取得方法
1. https://notify-bot.line.me/ にアクセス
2. LINEでログイン
3. 「マイページ」をクリック
4. 「トークンを発行する」をクリック
5. トークン名: `マッチングアプリ通知テスト`
6. 送信先: `1:1でLINE Notifyから通知を受け取る`
7. 「発行する」をクリック
8. 表示されたトークンをコピー（一度しか表示されません）

---

## テストデータ準備SQL

以下のSQLをSupabase SQL Editorで実行してください。
`YOUR_LINE_NOTIFY_TOKEN` を実際のトークンに置き換えてください。

```sql
-- 1. LINE通知を有効化
INSERT INTO user_settings (user_id, line_notify_token, line_notify_enabled)
VALUES (
  (SELECT id FROM auth.users WHERE email = 'test@example.com'),
  'YOUR_LINE_NOTIFY_TOKEN',
  true
)
ON CONFLICT (user_id) DO UPDATE 
SET line_notify_token = 'YOUR_LINE_NOTIFY_TOKEN',
    line_notify_enabled = true;

-- 2. 明日のデート予定を作成
INSERT INTO events (user_id, profile_id, event_date)
SELECT 
  (SELECT id FROM auth.users WHERE email = 'test@example.com'),
  p.id,
  CURRENT_DATE + INTERVAL '1 day'
FROM profiles p
WHERE p.user_id = (SELECT id FROM auth.users WHERE email = 'test@example.com')
  AND p.name = '山田花子'
LIMIT 1;

-- 3. 昨日の未更新イベントを作成
INSERT INTO events (user_id, profile_id, event_date, comment)
SELECT 
  (SELECT id FROM auth.users WHERE email = 'test@example.com'),
  p.id,
  CURRENT_DATE - INTERVAL '1 day',
  NULL
FROM profiles p
WHERE p.user_id = (SELECT id FROM auth.users WHERE email = 'test@example.com')
  AND p.name = '佐藤美咲'
LIMIT 1;
```

## 実行後の確認

### 1. Edge Functionを実行
Supabase Dashboard → Edge Functions → send-daily-notifications → RUN

### 2. 期待される結果
LINEに以下の通知が届きます:
- `📅 明日は山田花子さんとのデートです！楽しんできてください✨`
- `📝 佐藤美咲さんとのデートの感想を記録しましょう！`

### 3. ログ確認
```sql
SELECT 
  nl.notification_type,
  nl.sent_at,
  p.name as profile_name
FROM notification_logs nl
LEFT JOIN profiles p ON nl.profile_id = p.id
ORDER BY nl.sent_at DESC
LIMIT 10;
```

## トラブルシューティング

### LINEに通知が届かない場合

1. **トークンが正しいか確認**
```sql
SELECT 
  CASE WHEN line_notify_token IS NULL THEN 'NULL' ELSE 'SET' END as token_status,
  line_notify_enabled
FROM user_settings
WHERE user_id = (SELECT id FROM auth.users WHERE email = 'test@example.com');
```

2. **トークンをテスト**
PowerShellで実行:
```powershell
curl -X POST https://notify-api.line.me/api/notify -H "Authorization: Bearer YOUR_LINE_NOTIFY_TOKEN" -H "Content-Type: application/x-www-form-urlencoded" -d "message=テスト通知"
```

3. **Edge Functionのログを確認**
Supabase Dashboard → Edge Functions → send-daily-notifications → Logs

## クリーンアップ

テスト後、以下のSQLでテストデータを削除:

```sql
-- テストイベントを削除
DELETE FROM events 
WHERE user_id = (SELECT id FROM auth.users WHERE email = 'test@example.com')
  AND event_date >= CURRENT_DATE - INTERVAL '2 days';

-- LINE通知を無効化
UPDATE user_settings
SET line_notify_enabled = false
WHERE user_id = (SELECT id FROM auth.users WHERE email = 'test@example.com');
```
