# LINE連携テスト手順

## 前提条件
✅ LINE Developersでの設定完了
✅ Webhook URL設定完了: `https://wpagpmjjgwsnowvnhmml.supabase.co/functions/v1/line-webhook`
✅ Webhookの利用: ON
✅ 応答メッセージ: OFF

## テスト手順

### 1. アプリケーションにログイン

1. ブラウザで http://localhost:5500/login.html を開く
2. 以下の情報でログイン：
   - Email: `test@example.com`
   - Password: `testpassword`

### 2. アカウント管理画面へ移動

1. ログイン後、ナビゲーションから「アカウント」をクリック
2. 「外部連携設定」セクションまでスクロール

### 3. LINE連携を実行

1. 「LINE通知」セクションを確認
   - 状態: 未連携 と表示されているはず
   
2. 「ＬＩＮＥと連携する」ボタンをクリック
   - 連携コード（6桁の英数字）が表示される
   - 例: `ABC123`
   
3. 新しいタブでLINE友だち追加画面が開く

4. LINEアプリで「マッチングアプリ管理Bot」を友だち追加
   - スマホでQRコードをスキャン、または
   - LINE IDで検索: `@840izdny`

5. 友だち追加後、自動で連携コードが送信される
   - メッセージ例: `連携コード:ABC123`

6. Botから返信が来ることを確認
   - 「連携が完了しました！」などのメッセージ

### 4. 連携完了を確認

1. ブラウザのアカウント管理画面に戻る

2. ページをリロード（F5キー）

3. LINE通知セクションを確認：
   - ✅ 状態: 連携済み（緑色）
   - ✅ 「テストメッセージを送信」ボタンが表示
   - ✅ 「ＬＩＮＥ連携を解除」ボタンが表示

### 5. テストメッセージ送信

1. 「テストメッセージを送信」ボタンをクリック

2. LINEアプリを確認
   - Botからテストメッセージが届くことを確認

3. ブラウザに「テストメッセージを送信しました！」と表示される

### 6. Webhookのテスト

1. LINEアプリでBotにメッセージを送信
   - 例: 「こんにちは」

2. Botから返信が来ることを確認
   - 「メッセージを受信しました」など

3. Supabaseダッシュボードでログを確認（オプション）
   - https://supabase.com/dashboard
   - プロジェクト選択 → Functions → Logs
   - `line-webhook` のログを確認

## 期待される結果

### ✅ 成功時
- LINE連携が「連携済み」と表示される
- テストメッセージがLINEに届く
- Botにメッセージを送ると返信が来る
- アカウント管理画面で連携解除ボタンが表示される

### ❌ 失敗時のトラブルシューティング

#### 連携コードが送信されない
- LINE Developersで「Webhookの利用」がONになっているか確認
- Webhook URLが正しいか確認
- Supabase Functionsのログでエラーを確認

#### テストメッセージが届かない
- LINE連携が本当に完了しているか確認（ページをリロード）
- Supabaseの環境変数 `LINE_CHANNEL_ACCESS_TOKEN` が設定されているか確認
- Supabase Functionsのログでエラーを確認

#### Botからの返信がない
- 「応答メッセージ」がOFFになっているか確認
- Webhook URLの「検証」ボタンをクリックして成功するか確認
- Supabase Functionsが正常に動作しているか確認

## 次のステップ

LINE連携が成功したら：

1. **自動テストを再実行**
   ```bash
   npm test
   ```
   - ACCT-003とACCT-004のテストが実行されるはず

2. **LINE連携解除のテスト**
   - アカウント管理画面で「ＬＩＮＥ連携を解除」をクリック
   - 確認ダイアログで「OK」
   - 状態が「未連携」に戻ることを確認

3. **本番環境へのデプロイ準備**
   - すべてのテストが合格したら本番環境へデプロイ
