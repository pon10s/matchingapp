# テスト範囲定義書

## テストレベルの定義

### 単体テスト（Unit Test）
**対象**: 個別の関数・メソッド単位
**範囲**: 
- バリデーション関数
- データ変換関数
- 計算ロジック
- 状態管理関数

### 結合テスト1（Integration Test 1）
**対象**: 画面内の機能統合
**範囲**:
- 画面表示とデータ取得の連携
- フォーム入力とバリデーション
- ボタン操作と処理実行
- 画面内の状態遷移

### 結合テスト2（Integration Test 2）
**対象**: 画面間の機能統合・エンドツーエンド
**範囲**:
- 画面遷移フロー
- データの永続化と取得
- 外部API連携（LINE, Gemini）
- 通知機能の統合

## 結合テスト2対象

### 1. プロフィール→デート登録フロー
- プロフィール作成 → デート登録 → カレンダー表示

### 2. デート→感想記録フロー
- デート登録 → 感想未入力 → ホーム画面で更新

### 3. ステータス変更フロー
- プロフィール作成 → デート複数回 → ステータス変更 → 統計反映

### 4. LINE通知フロー
- LINE連携 → デート登録（明日） → 通知送信
- LINE連携 → デート実施（昨日・未コメント） → 通知送信
- LINE連携 → プロフィール15日未更新 → 通知送信

### 5. Gemini AIフロー
- Gemini設定 → プロフィール・デート登録 → AIアドバイス表示

### 6. 画像管理フロー
- 画像アップロード → トリミング → 保存 → プロフィール表示

### 7. 終了理由フロー
- プロフィール作成 → ステータス「終了」変更 → 終了理由入力 → 詳細表示

## テスト優先度

### 優先度A（高）- 必須機能
- 認証フロー
- プロフィール管理フロー
- デート管理フロー
- LINE通知フロー

### 優先度B（中）- 重要機能
- ホーム画面フロー
- アカウント管理フロー
- 統計グラフ表示

### 優先度C（低）- 補助機能
- Gemini AIフロー
- 画像トリミング詳細
- 検索・フィルタ詳細

---

## テスト環境

### 単体テスト
- 環境: Jest（または手動テスト）
- データ: モックデータ使用

### 結合テスト1
- 環境: Playwright
- データ: テスト用データベース

### 結合テスト2
- 環境: Playwright + 実際のSupabase
- データ: テスト用アカウント（test@example.com）
