# テストデータ投入手順

## 前提条件
- Supabaseプロジェクトが作成済み
- config.jsにSupabase接続情報が設定済み

## 手順

### 1. テストユーザーの作成

アプリのログイン画面から新規登録を実行：
- メールアドレス: `test@example.com`
- パスワード: `testpassword`
- ニックネーム: `テストユーザー`

### 2. Supabaseダッシュボードでテストデータ投入

1. [Supabase Dashboard](https://supabase.com/dashboard) にアクセス
2. プロジェクトを選択
3. 左メニューから「SQL Editor」を選択
4. `docs/test/insert-test-data.sql` の内容をコピー＆ペースト
5. 「Run」ボタンをクリック

### 3. データ確認

SQL Editorで以下を実行して確認：

```sql
SELECT 
  p.name,
  p.status,
  p.app
FROM profiles p
WHERE p.user_id = (SELECT id FROM auth.users WHERE email = 'test@example.com')
ORDER BY p.status;
```

期待結果：
- 山田花子（本命、Pairs）
- 佐藤美咲（あり、Omiai）
- 鈴木愛（終了、Tinder）

### 4. テスト実行

```bash
npm test
```

## データクリーンアップ

テスト後にデータを削除する場合：

```sql
-- イベント削除
DELETE FROM events 
WHERE user_id = (SELECT id FROM auth.users WHERE email = 'test@example.com');

-- プロフィール削除
DELETE FROM profiles 
WHERE user_id = (SELECT id FROM auth.users WHERE email = 'test@example.com');
```
