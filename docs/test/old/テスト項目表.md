## 4. テストケース（詳細）

### 4.1 PROF-001: プロフィール新規登録（正常系）

**目的:** プロフィールが正常に登録できることを確認

**前提条件:**
- ログイン済み
- プロフィール一覧画面を表示

**テストデータ:**
- 名前: テスト太郎
- 年齢: 25
- 職業: エンジニア
- 住み: 東京
- ステータス: あり
- どんな人: テストで作成したプロフィールです

**操作手順:**
1. 新規登録ボタンをクリック
2. 名前に「テスト太郎」を入力
3. 年齢に「25」を入力
4. 職業に「エンジニア」を入力
5. 住みに「東京」を入力
6. ステータスで「あり」を選択
7. どんな人に「テストで作成したプロフィールです」を入力
8. 保存ボタンをクリック

**期待結果:**
- プロフィール一覧画面に遷移
- 一覧に「テスト太郎」が表示される
- ステータスが「あり」と表示される
- どんな人が「テストで作成したプロフィールです」と表示される

**実装ファイル:**
- `ProfileRegistrationTest.java`
