## テスト実行手順

1. **環境準備**
   - テストユーザー作成
   - テストデータ投入
   - ローカルサーバー起動

2. **手動テスト実行**
   - チェックリストに沿って各機能を確認
   - NGの場合は詳細を記録

3. **自動テスト実行**
   ```bash
   npm test
   ```

4. **結果記録**
   - 各テストケースの結果を記録
   - NGの場合は原因と修正方針を記載
