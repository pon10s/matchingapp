# 要件定義書

## 1. システム概要

### 1.1 システム名
マッチングアプリ管理システム（tenkai）

### 1.2 目的
マッチングアプリで出会った相手のプロフィール情報とデート履歴を一元管理し、効率的な関係管理を支援する。

### 1.3 対象ユーザー
マッチングアプリを利用している個人ユーザー

## 2. 機能要件

### 2.1 認証機能
- **FR-001**: ユーザー登録（メールアドレス、パスワード、ニックネーム）
- **FR-002**: ログイン（メールアドレス、パスワード）
- **FR-003**: ログアウト
- **FR-004**: パスワードリセット

### 2.2 プロフィール管理機能
- **FR-101**: プロフィール一覧表示
  - ステータス順ソート（本命 > あり > わからない > ビミョウ > 大人の関係 > 友達 > 終了）
  - 名前・どんな人での検索
  - アバター表示
- **FR-102**: プロフィール詳細表示
  - 全項目表示
  - 写真表示
  - 登録日時・更新日時表示
- **FR-103**: プロフィール新規登録
  - 必須項目: 名前
  - 任意項目: 年齢、身長、学歴、年収、職業、住み、ステータス、出会ったアプリ、どんな人、メモ
  - 写真アップロード（トリミング機能付き）
- **FR-104**: プロフィール編集
- **FR-105**: プロフィール削除（関連デートも削除）

### 2.3 デート管理機能
- **FR-201**: デート登録
  - 相手選択（プロフィールから）
  - 日付選択
  - 登録完了画面表示
- **FR-202**: デート編集
  - 日付変更
  - 感想入力
  - 相手変更
- **FR-203**: デート削除
- **FR-204**: デート一覧表示（カレンダー形式）
  - 年度別グループ化
  - 日付順ソート（昇順/降順切替）
  - 回数表示（初回、2回目...）
  - 感想表示

### 2.4 ホーム画面機能
- **FR-301**: 統計情報表示
  - プロフィール総数
  - 今後の予定数
  - 未更新イベント数
- **FR-302**: 未更新イベント一覧
  - 過去の日付で感想未入力のデート表示
  - インライン感想入力
  - インラインステータス更新

### 2.5 アカウント管理機能
- **FR-401**: ニックネーム変更
- **FR-402**: メールアドレス変更
- **FR-403**: パスワード変更
- **FR-404**: アカウント削除（全データ削除）
- **FR-405**: LINE Notify連携設定
  - トークン登録
  - 通知設定（ON/OFF）
- **FR-406**: Gemini APIキー設定
  - APIキー登録
  - AIアドバイス機能ON/OFF

### 2.6 終了理由管理機能
- **FR-501**: 終了理由の記録
  - 終了タイプ選択（自分起因/相手起因/相互合意）
  - 終了理由詳細（自由記述）
  - 終了日の記録
- **FR-502**: 終了理由の表示
  - プロフィール詳細画面で表示
  - ステータスが「終了」の場合のみ

### 2.7 統計ダッシュボード機能
- **FR-601**: ステータス別人数グラフ（円グラフ）
- **FR-602**: 月別デート回数推移（折れ線グラフ）
- **FR-603**: アプリ別出会い数（棒グラフ）
- **FR-604**: 平均デート回数表示（全体/ステータス別）
- **FR-605**: 統計情報の期間フィルタ（全期間/過去1年/過去6ヶ月/過去3ヶ月）

### 2.8 検索・フィルタ強化機能
- **FR-701**: ステータス複数選択フィルタ
- **FR-702**: アプリ選択フィルタ
- **FR-703**: 年齢範囲フィルタ（スライダー）
- **FR-704**: 年収範囲フィルタ（スライダー）
- **FR-705**: 最終デート日ソート（昇順/降順）
- **FR-706**: フィルタ条件の保存

### 2.9 AIアドバイス機能
- **FR-801**: ホーム画面にAIアドバイス表示
  - Google Gemini API使用
  - ユーザーの状況分析（デート頻度、ステータス変更履歴等）
  - パーソナライズされたアドバイス生成
- **FR-802**: アドバイスの種類
  - デート登録推奨（最近登録なし）
  - ステータス変更推奨（連続デート成功時）
  - 連絡推奨（長期間連絡なし）
  - 感想記録推奨（未更新イベント多数）

### 2.10 通知機能
- **FR-901**: LINE Notify連携
  - ユーザーがLINE Notifyトークン設定
  - 通知のON/OFF設定
- **FR-902**: 次回デート予定通知
  - 前日・当日の通知
- **FR-903**: 感想未入力リマインド
  - デート翌日に通知
- **FR-904**: ステータス変更推奨通知
  - 15日間ステータス変更なし
  - 対象: 友達・終了・大人の関係以外
- **FR-905**: 通知送信タイミング設定
  - 毎日の通知時刻設定（デフォルト: 20:00）

### 2.11 画像管理機能
- **FR-1001**: 写真正方形トリミング
  - アップロード時にトリミングUI表示
  - ドラッグで位置調整
  - リアルタイムプレビュー
  - 300x300pxに自動リサイズ

## 3. 非機能要件

### 3.1 性能要件
- **NFR-001**: ページ読み込み時間は3秒以内
- **NFR-002**: 画像アップロードは10秒以内

### 3.2 セキュリティ要件
- **NFR-101**: 認証にSupabase Authを使用
- **NFR-102**: 全データはユーザーIDで分離
- **NFR-103**: パスワードはハッシュ化して保存
- **NFR-104**: 写真はSupabase Storageに保存

### 3.3 ユーザビリティ要件
- **NFR-201**: レスポンシブデザイン（PC/スマホ対応）
- **NFR-202**: 直感的なUI/UX
- **NFR-203**: 日本語表示

### 3.4 互換性要件
- **NFR-301**: Chrome、Firefox、Safari、Edge最新版対応
- **NFR-302**: iOS Safari、Android Chrome対応

### 3.5 保守性要件
- **NFR-401**: バニラJavaScript使用（フレームワーク依存なし）
- **NFR-402**: モジュール化されたコード構成

### 3.6 外部サービス連携要件
- **NFR-501**: Chart.js使用（グラフ表示）
- **NFR-502**: Google Gemini API使用（AIアドバイス）
  - ユーザーが各自APIキー取得・設定
  - 無料枠: 60リクエスト/分
- **NFR-503**: LINE Notify API使用（通知）
  - ユーザーが各自トークン取得・設定
  - 完全無料
- **NFR-504**: Supabase Edge Functions使用（定期通知）
  - 1日1回の定期実行
  - 無料枠内で運用

## 4. 制約事項

### 4.1 技術制約
- フロントエンド: HTML5、CSS3、JavaScript（ES6+）
- バックエンド: Supabase（PostgreSQL、Auth、Storage、Edge Functions）
- グラフライブラリ: Chart.js（CDN）
- AI API: Google Gemini API
- 通知API: LINE Notify API
- ホスティング: GitHub Pages

### 4.2 運用制約
- インターネット接続必須
- Supabaseアカウント必須
- LINE Notify連携（オプション、通知機能使用時）
- Google Gemini APIキー（オプション、AIアドバイス使用時）

## 5. 用語定義

| 用語 | 定義 |
|------|------|
| プロフィール | マッチングアプリで出会った相手の情報 |
| デート | 相手との会う予定または履歴 |
| ステータス | 相手との関係性（本命、あり、わからない等） |
| 未更新イベント | 過去の日付で感想が未入力のデート |
| 戦歴 | デート履歴のカレンダー表示 |
| 終了理由 | ステータスが「終了」になった理由と経緯 |
| AIアドバイス | ユーザーの状況に応じた行動提案 |
| LINE Notify | LINEで通知を受け取るサービス |
