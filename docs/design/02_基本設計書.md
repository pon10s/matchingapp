## 4. データベース設計

### 4.1 ER図

```
[users] (Supabase Auth管理)
    ├─ id (UUID, PK)
    ├─ email (string)
    ├─ user_metadata.nickname (string)
    └─ created_at (timestamp)

[profiles]
    ├─ id (UUID, PK)
    ├─ user_id (UUID, FK → users.id)
    ├─ name (string, NOT NULL)
    ├─ age (integer)
    ├─ height (integer)
    ├─ education (string)
    ├─ income (string) ← 選択式に変更
    ├─ occupation (string)
    ├─ residence (string)
    ├─ status (string)
    ├─ app (string)
    ├─ summary (text)
    ├─ memo (text)
    ├─ photo_url (string)
    ├─ end_reason_type (string) ← 新規
    ├─ end_reason_detail (text) ← 新規
    ├─ created_at (timestamp)
    └─ updated_at (timestamp)

[events]
    ├─ id (UUID, PK)
    ├─ user_id (UUID, FK → users.id)
    ├─ profile_id (UUID, FK → profiles.id, ON DELETE CASCADE)
    ├─ event_date (date, NOT NULL)
    ├─ comment (text)
    ├─ created_at (timestamp)
    └─ updated_at (timestamp)

[user_settings] ← 新規
    ├─ id (UUID, PK)
    ├─ user_id (UUID, FK → users.id, UNIQUE)
    ├─ line_notify_token (text)
    ├─ line_notify_enabled (boolean)
    ├─ gemini_api_key (text)
    ├─ gemini_enabled (boolean)
    ├─ notification_time (time)
    ├─ created_at (timestamp)
    └─ updated_at (timestamp)

[notification_logs] ← 新規
    ├─ id (UUID, PK)
    ├─ user_id (UUID, FK → users.id)
    ├─ profile_id (UUID, FK → profiles.id)
    ├─ notification_type (string)
    ├─ sent_at (timestamp)
    └─ created_at (timestamp)

[profile-photos] (Supabase Storage)
    └─ {user_id}/{profile_id}/photo.jpg
```

### 4.2 テーブル定義

#### profiles テーブル

| カラム名 | 型 | NULL | デフォルト | 説明 |
|---------|-----|------|-----------|------|
| id | UUID | NOT NULL | uuid_generate_v4() | プロフィールID（主キー） |
| user_id | UUID | NOT NULL | - | ユーザーID（外部キー） |
| name | VARCHAR(100) | NOT NULL | - | 名前 |
| age | INTEGER | NULL | - | 年齢 |
| height | INTEGER | NULL | - | 身長（cm） |
| education | VARCHAR(200) | NULL | - | 学歴 |
| income | VARCHAR(20) | NULL | - | 年収（選択式） |
| occupation | VARCHAR(100) | NULL | - | 職業 |
| residence | VARCHAR(100) | NULL | - | 住所 |
| status | VARCHAR(50) | NULL | - | ステータス |
| app | VARCHAR(100) | NULL | - | 出会ったアプリ |
| summary | TEXT | NULL | - | どんな人 |
| memo | TEXT | NULL | - | メモ |
| photo_url | TEXT | NULL | - | 写真URL |
| end_reason_type | VARCHAR(20) | NULL | - | 終了タイプ（自分起因/相手起因/相互合意） |
| end_reason_detail | TEXT | NULL | - | 終了理由詳細 |
| created_at | TIMESTAMP | NOT NULL | now() | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL | now() | 更新日時 |

**年収の選択肢:**
- 不明
- 〜300万
- 300〜500万
- 500〜700万
- 700〜1000万
- 1000〜1500万
- 1500〜2000万
- 2000〜3000万
- 3000〜5000万
- 5000万以上

**インデックス:**
- PRIMARY KEY (id)
- INDEX (user_id)

**制約:**
- FOREIGN KEY (user_id) REFERENCES auth.users(id) ON DELETE CASCADE

#### events テーブル

| カラム名 | 型 | NULL | デフォルト | 説明 |
|---------|-----|------|-----------|------|
| id | UUID | NOT NULL | uuid_generate_v4() | イベントID（主キー） |
| user_id | UUID | NOT NULL | - | ユーザーID（外部キー） |
| profile_id | UUID | NOT NULL | - | プロフィールID（外部キー） |
| event_date | DATE | NOT NULL | - | デート日付 |
| comment | TEXT | NULL | - | 感想 |
| created_at | TIMESTAMP | NOT NULL | now() | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL | now() | 更新日時 |

**インデックス:**
- PRIMARY KEY (id)
- INDEX (user_id)
- INDEX (profile_id)
- INDEX (event_date)

**制約:**
- FOREIGN KEY (user_id) REFERENCES auth.users(id) ON DELETE CASCADE
- FOREIGN KEY (profile_id) REFERENCES profiles(id) ON DELETE CASCADE

#### user_settings テーブル

| カラム名 | 型 | NULL | デフォルト | 説明 |
|---------|-----|------|-----------|------|
| id | UUID | NOT NULL | uuid_generate_v4() | 設定ID（主キー） |
| user_id | UUID | NOT NULL | - | ユーザーID（外部キー、UNIQUE） |
| line_notify_token | TEXT | NULL | - | LINE Notifyトークン |
| line_notify_enabled | BOOLEAN | NOT NULL | false | LINE通知有効フラグ |
| gemini_api_key | TEXT | NULL | - | Gemini APIキー |
| gemini_enabled | BOOLEAN | NOT NULL | false | AIアドバイス有効フラグ |
| notification_time | TIME | NOT NULL | 20:00:00 | 通知送信時刻 |
| created_at | TIMESTAMP | NOT NULL | now() | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL | now() | 更新日時 |

**インデックス:**
- PRIMARY KEY (id)
- UNIQUE INDEX (user_id)

**制約:**
- FOREIGN KEY (user_id) REFERENCES auth.users(id) ON DELETE CASCADE

#### notification_logs テーブル

| カラム名 | 型 | NULL | デフォルト | 説明 |
|---------|-----|------|-----------|------|
| id | UUID | NOT NULL | uuid_generate_v4() | ログID（主キー） |
| user_id | UUID | NOT NULL | - | ユーザーID（外部キー） |
| profile_id | UUID | NULL | - | プロフィールID（外部キー） |
| notification_type | VARCHAR(50) | NOT NULL | - | 通知タイプ |
| sent_at | TIMESTAMP | NOT NULL | now() | 送信日時 |
| created_at | TIMESTAMP | NOT NULL | now() | 作成日時 |

**通知タイプ:**
- `upcoming_date` - 次回デート予定通知
- `pending_comment` - 感想未入力リマインド
- `status_change_reminder` - ステータス変更推奨通知

**インデックス:**
- PRIMARY KEY (id)
- INDEX (user_id, profile_id, notification_type)

**制約:**
- FOREIGN KEY (user_id) REFERENCES auth.users(id) ON DELETE CASCADE
- FOREIGN KEY (profile_id) REFERENCES profiles(id) ON DELETE CASCADE

## 5. 外部インターフェース設計

### 5.1 Supabase API

#### 認証API
- `supabaseClient.auth.signUp()` - ユーザー登録
- `supabaseClient.auth.signInWithPassword()` - ログイン
- `supabaseClient.auth.signOut()` - ログアウト
- `supabaseClient.auth.getUser()` - ユーザー情報取得
- `supabaseClient.auth.updateUser()` - ユーザー情報更新
- `supabaseClient.auth.resetPasswordForEmail()` - パスワードリセット

#### データベースAPI
- `supabaseClient.from('profiles').select()` - プロフィール取得
- `supabaseClient.from('profiles').insert()` - プロフィール登録
- `supabaseClient.from('profiles').update()` - プロフィール更新
- `supabaseClient.from('profiles').delete()` - プロフィール削除
- `supabaseClient.from('events').select()` - イベント取得
- `supabaseClient.from('events').insert()` - イベント登録
- `supabaseClient.from('events').update()` - イベント更新
- `supabaseClient.from('events').delete()` - イベント削除

#### ストレージAPI
- `supabaseClient.storage.from('profile-photos').upload()` - 写真アップロード
- `supabaseClient.storage.from('profile-photos').getPublicUrl()` - 公開URL取得

### 5.2 Chart.js（グラフ描画）
- CDN: `https://cdn.jsdelivr.net/npm/chart.js`
- 使用グラフ:
  - 円グラフ（ステータス別人数）
  - 折れ線グラフ（月別デート回数）
  - 棒グラフ（アプリ別出会い数）

### 5.3 Cropper.js（画像トリミング）
- CDN: `https://cdnjs.cloudflare.com/ajax/libs/cropperjs/1.6.1/cropper.min.js`
- 機能:
  - 正方形固定トリミング
  - 拡大・縮小・移動
  - 300x300pxリサイズ

### 5.4 Google Gemini API
- エンドポイント: `https://generativelanguage.googleapis.com/v1/models/gemini-pro:generateContent`
- 用途: マチアプネキのアドバイス生成
- 認証: ユーザーが各自APIキー設定
- 無料枠: 60リクエスト/分

### 5.5 LINE Notify API
- エンドポイント: `https://notify-api.line.me/api/notify`
- 用途: 通知送信
- 認証: ユーザーが各自トークン取得
- 完全無料

### 5.6 Supabase Edge Functions
- 関数名: `send-daily-notifications`
- 実行頻度: 毎日（ユーザー設定時刻、デフォルト20:00）
- 処理内容:
  1. 全ユーザーの通知設定取得
  2. 通知条件チェック
  3. LINE Notify送信
  4. notification_logsに記録
  5. エラー時1回リトライ

## 6. 共通部品設計

### 6.1 共通ナビゲーション
全画面（ログイン画面除く）に以下のナビゲーションを配置：
- ホーム
- プロフィール一覧
- デート登録
- 戦歴

### 6.2 共通関数（supabaseClient.js）
- `ensureLoggedIn()` - ログイン確認、未ログインならログイン画面へリダイレクト
- `logout()` - ログアウト処理

### 6.3 グラフ描画関数（chart-utils.js）
- `drawStatusChart(data)` - ステータス別円グラフ描画
- `drawMonthlyChart(data)` - 月別折れ線グラフ描画
- `drawAppChart(data)` - アプリ別棒グラフ描画

### 6.4 AIアドバイス関数（ai-advisor.js）
- `getAdvice(userData)` - Gemini APIでアドバイス生成
- `formatAdviceWithCharacter(text)` - ネキ風の口調に変換

### 6.5 通知関数（notification-utils.js）
- `checkNotificationConditions(user)` - 通知条件チェック
- `sendLineNotify(token, message)` - LINE通知送信
- `logNotification(userId, profileId, type)` - 通知ログ記録

- ボタンスタイル
- フォームスタイル
