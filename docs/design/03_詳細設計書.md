## 2. JavaScript関数仕様

### 2.1 共通関数（supabaseClient.js）

#### ensureLoggedIn()
```javascript
/**
 * ログイン状態を確認し、未ログインの場合はログイン画面へリダイレクト
 * @returns {Promise<Object|null>} ユーザーオブジェクト、または null
 */
async function ensureLoggedIn()
```

**処理内容:**
1. `supabaseClient.auth.getUser()` でユーザー情報取得
2. ユーザーが存在しない場合、`login.html` へリダイレクト
3. ユーザーオブジェクトを返却

---

2. 年度が変わるごとに年度行を挿入
3. 各イベントに対して行を生成:
   - 日付（同日の2件目以降は空白）
   - アバター
   - 名前・回数
   - 感想
4. 行クリックで編集画面へ遷移

## 3. バリデーション仕様

### 3.1 クライアント側バリデーション

| 項目 | ルール | エラーメッセージ |
|------|--------|-----------------|
| メールアドレス | 必須、メール形式 | 「メールアドレスを正しく入力してください」 |
| パスワード | 必須、6文字以上 | 「パスワードは6文字以上で入力してください」 |
| パスワード確認 | パスワードと一致 | 「パスワードが一致しません」 |
| 名前 | 必須 | 「名前は必須です」 |
| 相手 | 必須 | 「相手を選択してください」 |
| 日付 | 必須 | 「日付を選択してください」 |
| 感想（未更新イベント更新時） | 必須 | 「感想を入力してください」 |

### 3.2 サーバー側バリデーション（Supabase）

- NOT NULL制約
- FOREIGN KEY制約
- データ型制約

## 4. エラーハンドリング

### 4.1 認証エラー
- ログイン失敗: アラート表示「メールアドレスまたはパスワードが正しくありません」
- セッション切れ: ログイン画面へリダイレクト

### 4.2 データベースエラー
- 取得失敗: コンソールエラー出力
- 登録/更新/削除失敗: アラート表示（エラーメッセージ）

### 4.3 ストレージエラー
- 写真アップロード失敗: アラート表示「写真のアップロードに失敗しました」
