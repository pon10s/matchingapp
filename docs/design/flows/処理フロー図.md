# 処理フロー図

## 1. ログインフロー

```mermaid
flowchart TD
    A[ログイン画面表示] --> B{ログイン/新規登録}
    B -->|ログイン| C[メール・パスワード入力]
    B -->|新規登録| D[ニックネーム・メール・パスワード入力]
    C --> E[signInWithPassword実行]
    D --> F[signUp実行]
    E --> G{認証成功?}
    F --> H{登録成功?}
    G -->|成功| I[ホーム画面へ遷移]
    G -->|失敗| J[エラーメッセージ表示]
    H -->|成功| K[確認メール送信通知]
    H -->|失敗| J
    K --> A
    J --> A
```

## 8. 通知送信フロー

```mermaid
flowchart TD
    A[Cron起動 毎日20:00] --> B[Edge Function実行]

    G --> H{予定あり?}

    H -->|No| J[昨日の未更新イベントチェック]

    P --> K
    K --> R[notification_logs記録]
    R --> Q

```
